================================================================================
                    NUST SOCIAL - FRONTEND DESIGN PLAN
                      Instagram-inspired Social Network
================================================================================

PROJECT OVERVIEW:
================================================================================
NUST SOCIAL is an Instagram-like social network platform specifically designed 
for NUST students with additional features like Societies and Marketplace. The 
design follows Instagram's modern UI/UX patterns while maintaining a responsive, 
beautiful, and intuitive interface.

   ├── Add tags

   └── Publish

3. Societies
   ├── Browse all societies
   ├── Search societies
   ├── View society posts
   ├── Join society
   └── View members

4. Marketplace
   ├── Browse products
   ├── Search/filter
   ├── View product details
   ├── Contact seller
   ├── Create listing
   └── View orders

5. Messages
   ├── View conversations
   ├── Open chat
   ├── Send messages
   └── Manage conversations

6. Profile
   ├── View own profile
   ├── Edit profile
   ├── View posts grid
   ├── View followers/following
   └── Access settings

LOGOUT FLOW:
───────────
1. Click logout

8. CONTENT STRUCTURE & EXAMPLES
================================================================================

POST TYPES:
├── Text Post: Caption + hashtags
├── Photo Post: 1 image + caption
├── Carousel: Multiple images + caption
├── Video Post: Video file + caption
├── Rumor Post: Poll-like (True/False voting)
├── Story-like: Temporary content (24hrs?)
└── Society Post: Posts specific to a society

POST METADATA:
├── Type: TEXT, PHOTO, VIDEO, RUMOR, CAROUSEL
├── Caption: Text with hashtags & mentions
├── Media: URLs to images/videos
├── Tags: Hashtags
├── Visibility: PUBLIC, ANONYMOUS, SOCIETY
├── Created At: Timestamp
├── Stats: Likes, Comments, Views
└── User Info: Author, Avatar, Username

COMMENT STRUCTURE:
├── ID: Unique identifier
├── Content: Comment text
├── Author: User info
├── Timestamp: Created at
├── Reactions: Like count
├── Nested: Replies to comments
└── Deleted: Soft delete option

SOCIETY STRUCTURE:
├── ID: Unique identifier
├── Name: Society name
├── Description: About society
├── Avatar: Logo/image
├── Members: Count + list
├── Posts: Feed specific to society
├── Created At: Timestamp
└── Status: Active/Inactive

MARKETPLACE LISTING:
├── ID: Product ID
├── Title: Product name
├── Description: Full description
├── Price: Amount
├── Images: Product photos
├── Seller: User profile
├── Category: Product category
├── Condition: New/Used
├── Status: Available/Sold
└── Created At: Timestamp

USER PROFILE DATA:
├── ID: User ID
├── Username: Unique handle
├── Avatar: Profile picture
├── Bio: Short bio
├── Followers: Count

├── Posts: Count
