# NUST SOCIAL - Auth Pages Design Preview\n\n## Overview\nThis document provides a complete overview of the beautiful, modern authentication pages designed for the NUST SOCIAL platform.\n\n## Pages Included\n\n### 1. **Login Page** (`/app/auth/login/page.tsx`)\n- **Color Scheme**: Purple-Pink Gradient\n- **Features**:\n  - Email input with emoji icon\n  - Password input with show/hide toggle\n  - Remember me checkbox\n  - Forgot password link\n  - Social login buttons (Google, Facebook)\n  - Glassmorphism design with animated background\n  - Error alert display\n  - Loading state with spinner\n  - Sign up link for new users\n  - Terms of Service and Privacy Policy links\n\n### 2. **Register Page** (`/app/auth/register/page.tsx`)\n- **Color Scheme**: Blue-Cyan Gradient\n- **Features**:\n  - Full name input with user icon\n  - Email input with email icon\n  - Batch year selector dropdown\n  - Password input with show/hide toggle\n  - Confirm password input with show/hide toggle\n  - Terms of Service checkbox\n  - Form validation\n  - Social signup buttons\n  - Sign in link for existing users\n  - Animated gradient background\n  - Loading state\n  - Error handling\n\n### 3. **OTP Verification Page** (`/app/auth/otp-verify/page.tsx`)\n- **Color Scheme**: Green-Emerald Gradient\n- **Features**:\n  - 6-digit OTP input with individual boxes\n  - Auto-focus between input fields\n  - Backspace navigation support\n  - Resend OTP button with 60-second cooldown\n  - Success and error alerts\n  - Email confirmation display\n  - Info box about spam folder\n  - Sign up again link\n  - Animated background\n  - Loading states\n\n---\n\n## Design System Features\n\n### Color Palettes\n\n#### Login (Purple-Pink)\n```\nGradient: from-purple-500 to-pink-500\nHover: from-purple-600 to-pink-600\nAccent: purple-400, pink-400\nBackground: from-slate-900 via-purple-900 to-slate-900\n```\n\n#### Register (Blue-Cyan)\n```\nGradient: from-blue-500 to-cyan-500\nHover: from-blue-600 to-cyan-600\nAccent: blue-400, cyan-400\nBackground: from-slate-900 via-blue-900 to-slate-900\n```\n\n#### OTP Verify (Green-Emerald)\n```\nGradient: from-green-500 to-emerald-500\nHover: from-green-600 to-emerald-600\nAccent: green-400, emerald-400\nBackground: from-green-900 via-emerald-900 to-slate-900\n```\n\n### Typography\n- **Headings**: 3xl bold, white text\n- **Subtitles**: sm, gray-300\n- **Labels**: sm semibold, gray-200\n- **Body**: sm, gray-300\n- **Muted**: xs, gray-400/500\n\n### Components\n\n#### Input Fields\n- Rounded corners (xl)\n- Glassmorphism background (white/5)\n- Subtle border (white/10)\n- Icon support on the right\n- Smooth focus transitions\n- Password visibility toggle\n- Helper text support\n\n#### Buttons\n- Gradient primary CTA buttons\n- Secondary outline buttons\n- Full width support\n- Loading spinner animation\n- Disabled state styling\n- Smooth hover effects with shadow\n\n#### Cards\n- Glassmorphism effect (backdrop-blur-xl)\n- Semi-transparent white background (white/10)\n- Subtle border (white/20)\n- 3xl border radius\n- Shadow effects\n- Smooth transitions\n\n#### Alerts\n- Error (red): `bg-red-500/10 border-red-500/30`\n- Success (green): `bg-green-500/10 border-green-500/30`\n- Info (blue): `bg-blue-500/10 border-blue-500/30`\n- Warning (yellow): `bg-yellow-500/10 border-yellow-500/30`\n\n### Animations\n\n#### Blob Animation\n- 7-second infinite loop\n- Smooth translate and scale transformations\n- 3 independent blobs with 2s and 4s delays\n- Creates depth and motion\n\n#### Loading Spinner\n- Rotating border animation\n- Used in buttons and submit states\n- Clean, minimal design\n\n#### Transitions\n- All transitions use `duration-200`\n- Smooth color, border, and shadow transitions\n- Focus ring animations\n\n---\n\n## User Experience Features\n\n### Accessibility\n- ✅ Proper semantic HTML\n- ✅ Form labels for all inputs\n- ✅ Error messages clearly
